# Power BI Practice Dashboards

This repository contains a collection of Power BI dashboards created as part of my data analytics learning journey. These projects focus on data cleaning, data modeling, KPI tracking, visualization design, and business insights using real-world datasets.

## Dashboards Included

### 1. Amazon Sales Analytics Dashboard
- Analyzed sales performance and revenue trends
- Identified top-performing products and categories
- Tracked sales KPIs and customer purchasing patterns

### 2. IBM HR Analytics Dashboard
- Explored employee attrition and workforce trends
- Analyzed department-wise employee distribution
- Monitored HR metrics and retention indicators

### 3. Sales Data Dashboard
- Visualized sales performance across different dimensions
- Tracked revenue, profit, and customer metrics
- Created interactive filters for deeper analysis

### 4. Hotel Booking Dashboard
- Analyzed booking trends and customer behavior
- Monitored cancellations and reservation patterns
- Evaluated hotel performance metrics

### 5. Flights Performance Dashboard
- Analyzed over 1 million flight records
- Tracked on-time performance, delays, and cancellations
- Identified airline and airport performance trends
- Explored flight traffic patterns across different periods
